# AnimalTracker v0.2.0 - 立即使用指南

## 🚀 快速开始（3步）

### 步骤 1：启动应用
```bash
cd C:\Users\cheng\.openclaw\workspace\AnimalTracker
streamlit run app.py
```

### 步骤 2：打开浏览器
访问：http://localhost:8501

### 步骤 3：使用新功能
1. 在侧边栏找到"追踪算法 (v0.2.0 新功能)"
2. 选择"增强追踪器（v0.2.0 ⭐新功能）"
3. 选择"平衡模式（推荐）"
4. 勾选"启用光流估计"和"启用匈牙利匹配"
5. 上传视频开始追踪

## ✨ 新功能说明

### 增强追踪器
基于 STCS 2024 论文，包含：
- **光流估计**：提高长期追踪稳定性（IDF1 +5-10%）
- **匈牙利匹配**：提高匹配准确率（+15-20%）
- **多阶段关联**：整合多种匹配策略

### 预设配置

#### 平衡模式（推荐）
- 适合：日常研究使用
- 特点：性能与准确率平衡
- 配置：光流✓ + 匈牙利✓

#### 高精度模式
- 适合：论文发表、关键实验
- 特点：最高准确率
- 配置：光流✓ + 匈牙利✓ + Re-ID✓

#### 快速模式
- 适合：实时处理
- 特点：最快速度
- 配置：光流✗ + 匈牙利✓

## 🆘 问题排查

### Q: 新功能在哪里？
A: 在侧边栏找到"追踪算法 (v0.2.0 新功能)"部分

### Q: 如何获得最佳效果？
A: 选择"增强追踪器" + "平衡模式" + 启用所有选项

A: 选择"高精度模式"并启用所有功能
