2. 选择 **"vmTracker (v0.3.0 ⭐推荐)"**
3. 选择预设配置：
   - **平衡模式（推荐）** - 日常研究
   - **高精度模式** - 密集场景、论文发表
   - **快速模式** - 实时处理

1. 选择视频文件
2. 点击 **"[START] 开始追踪"**
3. 等待处理完成
4. 查看结果和可视化

## 💡 核心技术

### 1. 虚拟标记系统

**原理：**
- 使用高置信度检测点作为虚拟标记
- 无需人工标注
- 自动生成稳定的身份锚点

**优势：**
```
传统方法：
  人工标注 100-1000 张图片 → 训练模型 → 追踪
  耗时：数天到数周 ❌

vmTracking：
  预训练模型 → 自动生成虚拟标记 → 追踪
  耗时：数小时 ✅
```

### 2. 身份锚点机制

**功能：**
- 每个动物关联唯一的虚拟标记组合
- 即使重叠也能区分身份
- 基于历史轨迹预测位置

**应用场景：**
```
密集场景：4只小鼠在一个小笼子里

问题：
  - 小鼠A和小鼠B重叠90%
  - 传统方法：无法区分 ❌
  - vmTracking：通过虚拟标记历史判断 ✅
```

### 3. 密集场景优化

**策略：**
- 时间一致性检查
- 全局身份优化
- 遮挡鲁棒性增强

## 📁 代码示例

### 基础使用

```python
from src.tracking.vmtracker import create_vm_tracker

# 创建追踪器
tracker = create_vm_tracker(preset='balanced')

# 处理视频
for frame in video:
    detections = detector.detect(frame)
    tracks = tracker.update(frame, detections)

    # tracks 包含所有动物轨迹
    for track_id, track in tracks.items():
        print(f"动物 {track_id}: {track.center}")
```

### 预设配置

```python
# 高精度模式（慢但准确）
tracker = create_vm_tracker(preset='high_accuracy')

# 平衡模式（推荐）
tracker = create_vm_tracker(preset='balanced')

# 快速模式（快但精度略低）
tracker = create_vm_tracker(preset='fast')
```
