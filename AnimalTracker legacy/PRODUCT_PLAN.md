# 基于 STCS 和 segTracker 的产品开发方案

## 🎯 产品定位

**产品名称：AnimalTracker Pro**

**产品定位：** 基于 STCS 框架的专业小动物行为追踪分析平台

**目标用户：**
- 科研院所（神经科学、行为学、药理学）
- 制药公司（药物研发、药效评估）
- CRO 公司（临床前研究服务）
